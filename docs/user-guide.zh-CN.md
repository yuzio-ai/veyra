# Veyra 使用指南

## 启动与安装

Veyra 需要 macOS 14 或更新版本，用于监控本机 Codex 任务与在线额度。从 [GitHub Releases](https://github.com/yuzio-ai/veyra/releases) 下载压缩包后，解压并将 `Veyra.app` 拖入“应用程序”目录即可。

应用启动后只出现在屏幕顶部菜单栏，不显示 Dock 图标。点击 Veyra 状态栏项目打开监控面板，右上角齿轮打开设置，电源按钮退出应用。

## 面板布局

弹窗采用 360pt 紧凑宽度，高度随内容自动伸缩。内容超过所在显示器的可用高度时，只有中间正文滚动，顶部保持固定。顶部左侧显示 Veyra 标志和名称，右侧放设置和退出按钮。“正在运行”标题行右侧以“本机”和状态圆点标明任务监控范围；悬停可查看提示：仅显示本机任务，不包含云端及其他设备。有可用更新时，底部显示更新提醒。

“正在运行”标题与数量右侧显示任务刷新进度，指针悬停在标题上可查看当前检查间隔。额度标题行最右侧的刷新按钮用于联网校准，校准进度显示在“额度”标题右侧；额度的冷却时间不影响本地任务自动刷新。

系统负责弹窗材质、圆角和阴影。macOS 26 上的固定操作按钮使用原生 Liquid Glass，旧系统使用原生 bordered 样式。外观跟随系统浅色和深色模式，并支持“减少透明度”与“增加对比度”。

## 任务与 token

运行中的任务先按会话所属项目分组，标题显示项目名称和运行数量。项目内保留完整的父子任务树；不同 worktree 在缺少明确归属时，通过公共 Git 目录匹配到同一项目。明确属于不同 Codex 项目的会话不会仅因共享仓库而合并。Codex 和 Codex CLI 的来源标签保留在任务行中。

缺少归属数据的桌面或 CLI 会话会尝试匹配项目目录；数据库项目字段为空或迁移状态本身不代表用户明确选择了无项目。具有明确“无项目”标记的 Codex 会话不按目录自动归属；迁移后数据库中已有的项目 ID 优先于旧标记。项目重叠且无法唯一识别时，放入“未归属项目”。同名项目保持独立，悬停标题可查看完整名称和项目目录。项目按最近活动排序，“未归属项目”位于最后；“状态待确认”区域内部采用相同分组。

任务按照父子关系组成任务家族并共用卡片。子任务使用缩进区分层级，结束或归档的父任务可以作为归属标题保留，但不会计入运行数。已结束的子任务不保留；无法可靠确认状态的任务显示在“状态待确认”区域。

当一次成功的进程检查找不到匹配的 Codex 进程，且任务已连续 24 小时没有新的活动记录时，状态待确认的任务会被隐藏。仍有匹配进程的任务无论多久都保留；进程检查失败时保持原有的待确认状态和警告。这一显示过滤不会修改任务历史。

每个任务展示模型、本轮运行时间和累计 Token。Codex 任务在累计用量上方展示最近记录的上下文占用，收起明细时仍显示。累计用量使用 K／M／B 缩写，悬停可查看精确值；缓存命中保留一位小数。点击累计用量行可独立展开“用量明细”和“会话统计”。明细保留完整数字及地区对应的千分位；“输出（含推理）”括号内为已包含的推理量。未知值显示“—”，不按零计算。刷新时仍存在任务的展开状态会保留，面板不会主动滚回顶部。

用量明细显示“API 费用（参考）”，统一使用美元。Codex 根据会话历史中可确认的模型分别计价，多模型分项放在字段旁的 ⓘ 中。未知模型或用量缺失不会视为零；可确认一部分时显示“部分估算”，完全无法确认时显示“—”和“无法估算”，详细原因放在 ⓘ 中。

费用采用内置官方基础价格表，随 Veyra 版本更新，点击 ⓘ 可查看价格核对日期和更多精度。估算不代表实际账单或订阅额度扣减，不含缓存写入加价、速度、长上下文、区域和工具等附加费用。仅在展开详情且面板可见时按需读取 Codex 费用历史；收起后停止读取费用历史，不影响原有任务刷新。

会话统计显示“工具调用用时（累计）”和“首 Token 延时（平均）”。工具用时仅计已记录的完成调用，并行或重叠区间只计一次；首 Token 延时对成功完成且具有有效记录的轮次求平均，并标注基于多少轮。主子任务分别统计，不合并子代理会话。

ⓘ 支持鼠标、Space 和 Return 打开说明，长内容可独立滚动；一个菜单只打开一个说明。Escape 先关闭说明并恢复按钮焦点，再次 Escape 关闭菜单。

子任务缺少名称或标题时，Veyra 依次使用任务路径末段、代理昵称或短 ID。路径作为标题下方的灰色等宽副标题，过长时从中间截断，悬停可查看完整路径；身份徽章显示分支图标和昵称，无昵称时显示“子代理”，悬停与辅助功能描述保留完整的“子代理：昵称”。任务行以小标题和最多两行正文展示当前轮次的公开进展；没有进展时显示最近的工具操作类别。

## 额度

Veyra 通过 Codex App Server 获取在线额度。启动时同步一次；有已确认运行任务时每分钟同步一次，空闲时每小时同步一次。任务开始或结束后会调整下一次同步时间。每种额度分别显示窗口名称、重置时间和剩余比例，日期使用系统区域格式。额度是否可读取由 Codex 路径、登录状态和接口结果决定，不读取服务商或模型配置。API Key 登录不提供 ChatGPT 订阅额度。

菜单栏按实际数据展示同一额度组的最多两个圆环，优先显示 Codex 组；没有 Codex 组时显示首个可用组。额度按周期从短到长排列，五小时在左、每周在右，未知周期放后，同周期主额度在前。只有一个窗口时显示一个圈，没有额度数据时保留单个“—”占位，Codex 路径不可用时隐藏额度圈。圈旁不加周期文字，悬浮说明和辅助功能标签包含各自周期、完整剩余百分比和任务数。

圈内数字不带百分号，与弧线按各自余量一起配色：剩余 ≥30% 时使用系统黑／白色，10%–<30% 时为橙色，<10% 时为红色；0% 不显示彩色弧线，数字 0 为红色。底环保持中性色，未知比例显示“—”。请求失败且账号未变时，保留上次的额度与颜色，悬浮说明和辅助功能标签在每项额度后加 `*` 标记缓存；没有旧数据时显示“暂无在线额度数据”。菜单打开高亮时使用系统选中色，关闭后恢复各自额度颜色；这些颜色不触发通知。

运行任务数显示在独立的 1pt 灰色细线圆角框中，增强对比度模式下边框加深，数字保持正常亮度。空闲显示 0，首次成功读取之前显示 —。读取失败时缓存任务降级为状态待确认；未确认会话不计入运行数。任务区域将读取失败、进程核对失败及记录不完整合并为一条“部分任务数据暂不可用，运行数量可能不完整”提示，“本机”状态点变为橙色，点击旁边的 ⓘ 可查看 Codex 任务数据的具体原因。历史读取失败后即使已回退至会话事件，只要无法确认结果完整，仍保留该提示。故障恢复后自动清除。未发现本地 Codex 数据时显示 0，并引导选择数据目录。悬停可查看额度窗口和任务数，VoiceOver 可读出同样的信息。

面板中的额度使用 56pt 圆环表示，从顶部顺时针填充。剩余 ≥30% 显示绿色，10%–<30% 显示橙色，<10% 显示红色；0% 不显示彩色弧线，缺失值显示中性底环和“—”，不足 1% 显示“<1%”。同一卡片中的不同额度窗口使用分割线区分。

点击额度刷新按钮可手动同步，已发起额度接口请求后的最短间隔为 60 秒；手动和自动请求共用同一限流与失败退避规则。请求中或冷却未到期时，刷新按钮灰显且不能通过鼠标或键盘触发；冷却期间显示“某时间后可校准”。请求结束且冷却到期后自动恢复，关闭再打开菜单不会绕过冷却。已发出额度请求后的失败退避依次为 5、15、30 分钟，服务端要求等待更久时取更长时间；若在初始化或登录检查阶段失败、尚未发出额度请求，则允许立即重试。

同步会临时启动本机 `codex app-server`，完成后立即关闭。打开菜单和任务刷新不会绕过额度刷新间隔。系统休眠期间暂停调度，唤醒后按当前任务状态检查是否到期。同步失败按上述缓存或空态规则展示，不再单独显示额度错误提示行，内部诊断仍保留错误分类。账号、登录状态、数据目录变化或 Codex 服务不可用时清空旧值。此前可用或手动配置的额度路径失效时，在独立的“Codex 额度”区域提示检查路径，并提供打开设置的入口；仅额度路径异常不会改变“本机”任务状态点，也不会将运行数量标为不完整。若任务数据目录同时不可读，任务区域仍显示相应的汇总提醒。

“可用重置次数”卡片展示接口返回的总次数，并按精确到期时间分组，最近到期的批次排在前面。日期使用本机时区，悬停可查看精确到秒的时间；缺少有效期的条目显示“到期时间未知”，明细不足时提示“部分到期信息暂不可用”。重置次数与额度卡片随在线同步更新，不再显示联网校准时间。

批次到期后显示“已到期 · 待校准”，总数改为“待校准”，点击联网校准获取新的真实次数。尚未校准时显示“联网校准后查看”；旧版接口未提供次数时显示“暂不可用”。Veyra 仅展示重置次数，不执行额度重置。

## 设置与自动发现

设置窗口为单页，包含快捷键、Codex 路径和更新设置。窗口内容超高时可以滚动。

路径留空时，Veyra 会按顺序查找：已安装的 Codex 桌面应用、用户级安装位置（`~/.local/bin/codex`、`~/.codex/packages/standalone/current/bin/codex`）、Homebrew（`/opt/homebrew/bin`、`/usr/local/bin`），最后再检查进程 `PATH`。默认数据目录使用 `CODEX_HOME`（该变量为空或只有空白时按未设置处理）；没有设置该环境变量时使用 `~/.codex`。

路径在按 Return、离开输入框或确认“选择…”后进行本地校验，合法修改自动生效，无需保存。无效输入会保留供修正，实际配置继续使用上次有效值；关闭设置会丢弃无效草稿。“恢复自动检测”会清除两项手动覆盖。Codex 状态表示本地路径是否可用，不代表已完成账号登录或联网验证。

从 Finder 启动的应用通常不会继承终端环境变量。如果自动发现结果不符合实际安装位置，可在终端运行 `which codex` 查看实际路径，再在设置中指定 Codex 可执行文件或数据目录。

## DSH 监控退役

DSH 任务监控及其路径设置已移除。升级后不会读取、迁移或删除已有 DSH 数据，原有目录偏好也不再使用。仅使用 DSH 的用户将无法继续通过 Veyra 监控其任务。历史发布说明保留当时的功能事实。

## 旧版服务商功能迁移

服务商管理、模型配置、连接测试和取钥命令已全部移除。新版本不会读取或写入旧连接库，不访问钥匙串，也不会自动修改 Codex 配置。

升级前，检查 Codex 配置中的认证命令是否调用 Veyra 的 `--provider-credential`。如果存在，请先在 Codex 中重新配置连接的认证方式；新版本收到此命令会快速返回非零，不返回 Key，也不启动界面。原先依赖该命令的连接会认证失败。

已有 `~/Library/Application Support/Veyra/ModelProfiles/` 目录中的连接库、缓存、模型目录及恢复记录保留，钥匙串项目也保留。不要删除 Codex 配置仍引用的模型目录。确认连接已完成重新配置且不再引用这些数据后，再自行决定是否清理旧文件和钥匙串项目；Veyra 不自动迁移、恢复或删除它们。
