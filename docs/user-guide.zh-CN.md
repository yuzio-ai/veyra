# Veyra 使用指南

## 启动与安装

Veyra 需要 macOS 14 或更新版本，可监控本机 Codex 或 dsh；仅监控 dsh 无需安装 Codex。从 [GitHub Releases](https://github.com/yuzio-ai/veyra/releases) 下载压缩包后，解压并将 `Veyra.app` 拖入“应用程序”目录即可。

应用启动后只出现在屏幕顶部菜单栏，不显示 Dock 图标。点击 Veyra 状态栏项目打开监控面板，右上角齿轮打开设置，电源按钮退出应用。

## 面板布局

弹窗采用 360pt 紧凑宽度，高度随内容自动伸缩。内容超过所在显示器的可用高度时，只有中间正文滚动，顶部保持固定。第一行左侧显示 Veyra 标志和名称，右侧放设置和退出按钮。第二行左侧以电脑图标、状态圆点和“本机活动”标明本机数据来源，Codex 可执行文件和数据目录可用时，右侧显示“当前服务商”与供应商下拉菜单。服务商名称来自当前新会话配置，运行中的旧任务可能仍使用其他服务商；悬停可查看完整名称和说明。外部配置发生变化时，页头会重新读取当前配置；重载保留未保存草稿、干净草稿下的操作提示和“设为默认”等选择，忙碌或正在发现模型、测试连接时的变更会排队处理。配置读取失败后按 5、15、30、60 秒退避自动重试，不需要再次改文件或关闭重开菜单；新配置会替换旧等待，恢复后只清除读取错误。底部不再常驻说明或操作按钮；有可用更新时仍显示更新提醒。

运行任务标题与数量右侧显示任务刷新进度，标题行最右侧提供刷新按钮。按钮左侧的信息图标会在指针悬停时显示当前检查间隔。额度标题行最右侧的刷新按钮用于联网校准，校准进度显示在“额度”标题右侧。两处刷新按钮使用相同的单箭头图标、尺寸和按钮样式，保留独立操作及加载状态；额度的冷却时间不影响本地任务刷新。

系统负责弹窗材质、圆角和阴影。macOS 26 上的固定操作按钮使用原生 Liquid Glass，旧系统使用原生 bordered 样式。外观跟随系统浅色和深色模式，并支持“减少透明度”与“增加对比度”。

## 任务与 token

运行中的任务先按会话所属项目分组，标题显示项目名称和运行数量。项目内保留完整的父子任务树；不同 worktree 在缺少明确归属时，通过公共 Git 目录匹配到同一项目。明确属于不同 Codex 项目的会话不会仅因共享仓库而合并。Codex、CLI 和 dsh 的来源标签保留在任务行中。

没有明确归属的 CLI 或 dsh 会话会尝试匹配项目目录；项目重叠且无法唯一识别时，放入“未归属项目”。同名项目保持独立，悬停标题可查看完整名称和项目目录。项目按最近活动排序，“未归属项目”位于最后；“状态待确认”区域内部采用相同分组。

任务按照父子关系组成任务家族并共用卡片。子任务使用缩进区分层级，结束或归档的父任务可以作为归属标题保留，但不会计入运行数。已结束的子任务不保留；无法可靠确认状态的任务显示在“状态待确认”区域。

当一次成功的进程检查找不到匹配的 Codex 进程，且任务已连续 24 小时没有新的活动记录时，状态待确认的任务会被隐藏。仍有匹配进程的任务无论多久都保留；进程检查失败时保持原有的待确认状态和警告。这一显示过滤不会修改任务历史。

每个任务展示模型、运行时间和累计 token。累计用量使用 K／M／B 缩写，悬停可查看精确值。点击用量行可独立展开“输入缓存占比”和“缓存读取、未缓存输入、输出（推理）”三项明细。明细保留完整数字；输出括号内为已包含的推理量。未知值显示“—”，不按零计算。刷新时仍存在任务的展开状态会保留，面板不会主动滚回顶部。

子任务缺少名称或标题时，Veyra 依次使用任务路径末段、代理昵称或短 ID。路径作为标题下方的灰色等宽副标题，过长时从中间截断，悬停可查看完整路径；昵称合并到“子代理：昵称”徽章。任务行以小标题和最多两行正文展示当前轮次的公开进展；没有进展时显示最近的工具操作类别。

## 额度

Veyra 通过 Codex App Server 获取在线额度。启动时同步一次；有已确认运行任务时每分钟同步一次，空闲时每小时同步一次。任务开始或结束后会调整下一次同步时间。每种额度分别显示窗口名称、重置时间和剩余比例。日期使用系统本地化的年月日与时分格式。切换到第三方供应商后，面板和菜单栏隐藏全部额度，并暂停额度请求；切回官方供应商后，遵守原有冷却和服务端等待时间再同步。设置了 `openai_base_url` 的自定义 OpenAI 网关同样隐藏官方额度。

菜单栏用圆环和不带百分号的放大数字显示主额度窗口的剩余比例，两者使用同一数值同步更新；悬停与辅助功能标签仍保留完整百分比。运行任务数显示在独立的圆角矩形中，不使用三角图标，空闲显示 0，首次成功读取之前显示 —。一个来源失败时保留另一来源的已确认运行数量，故障提示会说明数量可能不完整；未确认会话不计入运行数。两种来源均未发现时显示 0，并引导选择数据目录。悬停可查看额度窗口和任务数，VoiceOver 可读出同样的信息。

面板中的额度使用 56pt 圆环表示，从顶部顺时针填充。剩余 ≥30% 显示绿色，10%–<30% 显示橙色，<10% 显示红色；0% 不显示彩色弧线，缺失值显示中性底环和“—”，不足 1% 显示“<1%”。同一卡片中的不同额度窗口使用分割线区分。

点击额度刷新按钮可手动同步，已发起额度接口请求后的最短间隔为 60 秒；手动和自动请求共用同一限流与失败退避规则。同步会临时启动本机 `codex app-server`，完成后立即关闭。打开菜单和任务刷新不会绕过额度刷新间隔。系统休眠期间暂停调度，唤醒后按当前任务状态检查是否到期。网络失败会保留旧值并显示错误，账号或供应商变化时清空旧值。

“可用重置次数”卡片展示接口返回的总次数，并按精确到期时间分组，最近到期的批次排在前面。日期使用本机时区，悬停可查看精确到秒的时间；缺少有效期的条目显示“到期时间未知”，明细不足时提示“部分到期信息暂不可用”。重置次数与额度卡片随在线同步更新，不再显示联网校准时间。

批次到期后显示“已到期 · 待校准”，总数改为“待校准”，点击联网校准获取新的真实次数。尚未校准时显示“联网校准后查看”；旧版接口未提供次数时显示“暂不可用”。Veyra 仅展示重置次数，不执行额度重置。

## 设置与自动发现

设置窗口分为「通用」和「模型」。原有快捷键、路径及更新设置位于「通用」。

路径留空时，Veyra 会按顺序查找：已安装的 Codex 桌面应用、用户级安装位置（`~/.local/bin/codex`、`~/.codex/packages/standalone/current/bin/codex`）、Homebrew（`/opt/homebrew/bin`、`/usr/local/bin`），最后再检查进程 `PATH`。默认数据目录使用 `CODEX_HOME`（该变量为空或只有空白时按未设置处理）；没有设置该环境变量时使用 `~/.codex`。

路径在按 Return、离开输入框或确认“选择…”后进行本地校验，合法修改自动生效，无需保存。无效输入会保留供修正，实际配置继续使用上次有效值；关闭设置会丢弃无效草稿。“恢复自动检测”会清除两项手动覆盖。Codex 状态表示本地路径是否可用，不代表已完成账号登录或联网验证。

从 Finder 启动的应用通常不会继承终端环境变量。如果自动发现结果不符合实际安装位置，可在终端运行 `which codex` 查看实际路径，再在设置中指定 Codex 可执行文件或数据目录。

## 仅使用 dsh

无需安装 Codex。面板只显示本地任务，隐藏额度和供应商切换，也不进行额度同步、Codex 配置加载或配置重试。Codex 未安装属于正常状态；已有安装的登录、联网或读取故障仍会提示。

在“设置 → 通用 → dsh”查看检测状态或选择数据目录。优先使用手动路径，其次为去除首尾空白后的非空 `DSH_HOME`，最后为 `~/.dsh`。Finder 启动通常不继承终端环境变量，非默认安装建议直接选择目录。按 Return、离开输入框或确认目录选择后生效；无效输入不替换有效路径，清空路径或恢复自动检测可回到默认查找方式。

dsh 记录缺少明确项目归属时，仍按现有规则匹配 Codex 项目；没有可匹配项目则放入“未归属项目”。目录读取失败或此前可读的会话目录消失会显示来源明确的提示，恢复后自动清除。更换 dsh 路径不清空 Codex 任务或额度，更换 Codex 路径也不清空 dsh 任务。Veyra 始终只读这些任务数据。

## Codex 供应商

在「设置 → 模型」选择 DeepSeek、Kimi、GLM、MiniMax 或 MiMo。预置面向国内普通按量 API，不包含 Coding Plan。侧栏高亮表示正在编辑，勾选标记表示新会话默认供应商；配置状态、应用状态和具体问题显示在详情页。

填写 API Key 后点击「保存」，再点击模型区的「刷新模型」。保存只写入 Veyra 元数据及用户指定的钥匙串项，不会获取模型或修改 Codex 默认配置。首次使用需刷新列表并选择模型；应用不内置模型清单，也不自动选择第一项。替换 Key 后需重新刷新，新凭据不会复用旧 Key 的模型缓存。打开设置、启动应用和菜单切换不自动获取模型。

选择模型后，点击「保存并设为默认」或「设为默认」，再完全退出并重启 Codex。当前默认供应商可直接应用模型修改。应用时若内置供应商缺少匹配列表，会先尝试获取，失败则停止切换。高级选项提供地址、推理强度和上下文覆盖。供应商元数据中的上下文窗口和默认推理档位会在应用时采用，手动覆盖优先，缺失能力跟随 Codex 默认值。只有档位列表而没有默认档位时，不自动挑选一档。

Key 只存入本机系统钥匙串，界面不回填已保存的 Key。可更换或移除 Key；当前配置或恢复记录仍引用的 Key 无法移除。修改地址后必须填写新 Key，或明确确认允许原 Key 用于新地址。网络故障可使用匹配的数据目录、地址及凭据引用下的缓存；已知认证失败会阻止应用，需修复后重新刷新。

侧栏「添加服务商」创建自定义连接，支持无认证本地服务、手动模型 ID 和模型列表。远程地址使用 HTTPS，HTTP 仅允许回环地址；应用不自动追加 `/v1`。自定义连接固定使用 Responses API，可通过快捷菜单重命名、复制或删除。旧连接的协议不兼容时，可点击「改用 Responses API」修改草稿，再保存或设为默认；未测试连接仍需确认后才能应用。本地 ID 和旧模型目录路径不在设置中展示，已有标识和目录引用继续保留。旧连接保留原有身份；旧环境变量连接需用户填写 Key 后转换，不读取原环境变量值，复杂认证保留为 Codex 配置引用。

外部 Codex 配置变化会自动同步。配置同步只读磁盘上的 Codex 配置，不联网。选择「OpenAI（官方）」只打开其详情页；点击应用后才写配置。菜单栏供应商入口可切换已配置连接，当前项不能重复切换。未保存修改会提示保存、放弃或取消。

「测试连接」由用户主动触发，向所选服务发送固定的少量 Responses 模型请求，可能产生 API 费用。列表获取、模型测试和完整 Codex 工具能力分别验证；测试成功不代表余额或全部工具功能可用。未测试的自定义连接应用前需确认；已知协议不兼容或认证失败会阻止应用。

配置写入通过 Codex 的版本校验接口完成，外部修改冲突时停止写入并读回。成功后只改变新会话默认值，运行中的聊天仍使用其记录的模型。GUI 退出后，Codex 可调用 Veyra 的无界面取钥命令；移动应用后可用详情中的修复操作更新凭据命令路径，不必改动模型设置。钥匙串锁定时先在系统中解锁，再重试。
