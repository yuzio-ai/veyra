# Veyra 使用指南

## 启动与安装

Veyra 需要 macOS 14 或更新版本，并要求本机已经安装、登录 Codex 桌面端或 Codex CLI。从 [GitHub Releases](https://github.com/yuzio-ai/veyra/releases) 下载压缩包后，解压并将 `Veyra.app` 拖入“应用程序”目录即可。

应用启动后只出现在屏幕顶部菜单栏，不显示 Dock 图标。点击 Veyra 标志打开监控面板，底部齿轮打开设置，电源按钮退出应用。

## 面板布局

弹窗采用 360pt 紧凑宽度，高度随内容自动伸缩。内容超过所在显示器的可用高度时，只有中间正文滚动，应用标题和底部操作保持固定。标题栏左侧显示 Veyra 标志和名称，右侧显示状态圆点与“本机活动”。

运行任务标题与数量右侧显示任务刷新进度，标题行最右侧提供刷新按钮。按钮左侧的信息图标会在指针悬停时显示当前检查间隔。额度标题行最右侧的循环箭头用于联网校准，校准进度显示在“额度”标题右侧。

系统负责弹窗材质、圆角和阴影。macOS 26 上的固定操作按钮使用原生 Liquid Glass，旧系统使用原生 bordered 样式。外观跟随系统浅色和深色模式，并支持“减少透明度”与“增加对比度”。

## 任务与 token

任务按照父子关系组成任务家族并共用卡片。子任务使用缩进区分层级，结束或归档的父任务可以作为归属标题保留，但不会计入运行数。已结束的子任务不保留；无法可靠确认状态的任务显示在“状态待确认”区域。

当一次成功的进程检查找不到匹配的 Codex 进程，且任务已连续 24 小时没有新的活动记录时，状态待确认的任务会被隐藏。仍有匹配进程的任务无论多久都保留；进程检查失败时保持原有的待确认状态和警告。这一显示过滤不会修改任务历史。

每个任务展示模型、运行时间、输入、输出和累计 token。点击累计用量可以展开缓存输入与推理输出明细。刷新时仍存在任务的展开状态会保留，面板不会主动滚回顶部。

子任务缺少名称或标题时，Veyra 依次使用任务路径末段、代理昵称或短 ID。任务行最多展示两行当前轮次的公开进展；没有进展时显示最近的工具操作类别。

## 额度

Veyra 默认读取本地会话中的最新额度快照，不会在后台自动联网。每种额度分别显示窗口名称、重置时间、记录时间和剩余比例；菜单栏中的 `~` 表示数值来自本地快照。

额度使用 56pt 圆环表示，从顶部顺时针填充。剩余 ≥30% 显示绿色，10%–<30% 显示橙色，<10% 显示红色；0% 不显示彩色弧线，缺失值显示中性底环和“—”，不足 1% 显示“<1%”。同一卡片中的不同额度窗口使用分割线区分。

需要与当前登录账号核对时，点击额度刷新按钮执行一次联网校准。校准会临时启动本机 `codex app-server`，完成后立即关闭；启动应用、打开菜单、普通任务刷新和系统唤醒都不会触发额度网络请求。

“可用重置次数”卡片展示上次联网校准时的总次数，并按精确到期时间分组，最近到期的批次排在前面。日期使用本机时区，悬停可查看精确到秒的时间；缺少有效期的条目显示“到期时间未知”，明细不足时提示“部分到期信息暂不可用”。本地额度更新不会覆盖这张卡片，卡片保留自己的校准时间。

批次到期后显示“已到期 · 待校准”，总数改为“待校准”，点击联网校准获取新的真实次数。尚未校准时显示“联网校准后查看”；旧版接口未提供次数时显示“暂不可用”。Veyra 仅展示重置次数，不执行额度重置。

## 设置与自动发现

路径留空时，Veyra 会优先查找已安装的 Codex 桌面应用，再检查 `PATH` 和常见 CLI 安装位置。默认数据目录使用 `CODEX_HOME`；没有设置该环境变量时使用 `~/.codex`。

路径在按 Return、离开输入框或确认“选择…”后进行本地校验，合法修改自动生效，无需保存。无效输入会保留供修正，实际配置继续使用上次有效值；关闭设置会丢弃无效草稿。“恢复自动检测”会清除两项手动覆盖。Codex 状态表示本地路径是否可用，不代表已完成账号登录或联网验证。

从 Finder 启动的应用通常不会继承终端环境变量。如果自动发现结果不符合实际安装位置，请在设置中指定 Codex 可执行文件或数据目录。
