# Veyra 使用指南

## 启动与安装

Veyra 需要 macOS 14 或更新版本，并要求本机已经安装、登录 Codex 桌面端或 Codex CLI。从 [GitHub Releases](https://github.com/yuzio-ai/veyra/releases) 下载压缩包后，解压并将 `Veyra.app` 拖入“应用程序”目录即可。

应用启动后只出现在屏幕顶部菜单栏，不显示 Dock 图标。点击 Veyra 标志打开监控面板，底部图表按钮打开任务统计，齿轮打开设置，电源按钮退出应用。

## 面板布局

弹窗采用 360pt 紧凑宽度，高度随内容自动伸缩。内容超过所在显示器的可用高度时，只有中间正文滚动，应用标题和底部操作保持固定。标题栏左侧显示 Veyra 标志和名称，右侧显示状态圆点与“本机活动”。

运行任务标题与数量右侧显示任务刷新进度，标题行最右侧提供刷新按钮。按钮左侧的信息图标会在指针悬停时显示当前检查间隔。额度标题行最右侧的循环箭头用于联网校准，校准进度显示在“额度”标题右侧。

系统负责弹窗材质、圆角和阴影。macOS 26 上的固定操作按钮使用原生 Liquid Glass，旧系统使用原生 bordered 样式。外观跟随系统浅色和深色模式，并支持“减少透明度”与“增加对比度”。

## 任务与 token

任务按照父子关系组成任务家族并共用卡片。子任务使用缩进区分层级，结束或归档的父任务可以作为归属标题保留，但不会计入运行数。已结束的子任务不保留；无法可靠确认状态的任务显示在“状态待确认”区域。

当一次成功的进程检查找不到匹配的 Codex 进程，且任务已连续 24 小时没有新的活动记录时，状态待确认的任务会被隐藏。仍有匹配进程的任务无论多久都保留；进程检查失败时保持原有的待确认状态和警告。这一显示过滤不会修改任务历史。

每个任务展示模型、运行时间、输入、输出和累计 token。点击累计用量可以展开缓存输入与推理输出明细。刷新时仍存在任务的展开状态会保留，面板不会主动滚回顶部。

子任务缺少名称或标题时，Veyra 依次使用任务路径末段、代理昵称或短 ID。任务行最多展示两行当前轮次的公开进展；没有进展时显示最近的工具操作类别。

## 任务概览与统计分析

菜单栏底部图表按钮打开独立窗口，默认进入“概览”。顶部显示当前进行中、最近24小时需要关注、今日有活动的主任务。当前状态不受历史日期或筛选影响。进行中必须有可靠的本机进程证据；读取失败、证据不足或60秒没有更新时显示“—”，不能理解为零个任务。

需要关注包括近期最新轮次失败、中断及当前状态待确认的任务。后续新记录会覆盖旧结果，同一家族只出现一次。点击关注项可定位对应任务和执行记录；点击概况数字可聚焦列表，清除聚焦恢复原来的日期和筛选。

任务按项目和父子关系归组。主任务与后代合计为一个家族，资源不重复叠加；子任务可在详情中查看。项目路径相同才视为同一项目，即使显示名称相同。搜索命中子任务时保留主任务上下文。

选择任务后在右侧查看摘要及执行记录。小于1180pt宽度时进入独立详情，返回保留列表位置。执行记录最新在前，默认最近六轮，支持查看全部及结果筛选。展开某一轮查看完整时间、模型、来源及已有用量分项；路径和标识位于“任务信息”。“在Codex中打开”不可用时可以复制任务标识。

“统计分析”默认近30天，保留日、周、月、年和自定义范围。概览与分析各自保存期间和筛选条件。周从周一开始，日期采用系统时区；自定义范围包含结束日期。灰柱表示各日或周去重主任务，蓝线表示已记录Token，左右轴单位独立。周内同一任务只计一次，期间任务数不能直接相加每日任务数。

年度热力图显示截止今天的近一年，可切换任务数量和Token。每列一周、每周七行，颜色图例显示实际数值档位。无活动、缺失用量和未覆盖日期使用不同标记。选择两张图中的日期或日期菜单会联动任务明细；年度图选到当前期间之外时，顶部期间和组合图范围保持不变。清除日期选择可恢复期间明细。

Token按历史快照的可靠差值归入记录时间，不以任务累计值代替本期用量。部分缺失时显示已记录部分与缺失提示，全部未知显示“—”，不填零。图表缺失处断线，部分缺失使用标记。已结束轮次耗时按区间拆分并相加，包含并行轮次和轮内等待，不等于人的工作时长；未结束轮次另行标注。轮次正常结束不表示任务目标完成。

“更多统计”保留原有耗时、轮次、分位耗时、缓存比例、项目/模型/来源分布及可靠覆盖条件下的期间比较。“数据详情”显示覆盖、更新时间和缺失情况。源日志删除或截断后保留已索引记录，并标注来源不可用。

历史在窗口打开时每30秒增量更新，关闭后停止扫描。实时状态复用现有监控读数，不另建扫描器。本窗口仅覆盖当前目录的本机Codex历史，包含可读归档任务，不包含dsh、云端或其他设备。

“导出…”提供Markdown摘要与任务清单及CSV逐轮记录。导出使用完整选定期间与当前筛选，图表选日只影响屏幕明细；导出窗口会显示范围。可独立隐藏标题/标识和项目路径。CSV缺失数字字段留空，时间使用UTC ISO8601，期间为含开始、不含结束。

## 额度

Veyra 默认读取本地会话中的最新额度快照，不会在后台自动联网。每种额度分别显示窗口名称、重置时间、记录时间和剩余比例；菜单栏中的 `~` 表示数值来自本地快照。

额度使用 56pt 圆环表示，从顶部顺时针填充。剩余 ≥30% 显示绿色，10%–<30% 显示橙色，<10% 显示红色；0% 不显示彩色弧线，缺失值显示中性底环和“—”，不足 1% 显示“<1%”。同一卡片中的不同额度窗口使用分割线区分。

需要与当前登录账号核对时，点击额度刷新按钮执行一次联网校准。校准会临时启动本机 `codex app-server`，完成后立即关闭；启动应用、打开菜单、普通任务刷新和系统唤醒都不会触发额度网络请求。

“可用重置次数”卡片展示上次联网校准时的总次数，并按精确到期时间分组，最近到期的批次排在前面。日期使用本机时区，悬停可查看精确到秒的时间；缺少有效期的条目显示“到期时间未知”，明细不足时提示“部分到期信息暂不可用”。本地额度更新不会覆盖这张卡片，卡片保留自己的校准时间。

批次到期后显示“已到期 · 待校准”，总数改为“待校准”，点击联网校准获取新的真实次数。尚未校准时显示“联网校准后查看”；旧版接口未提供次数时显示“暂不可用”。Veyra 仅展示重置次数，不执行额度重置。

## 设置与自动发现

设置窗口分为「通用」和「供应商」。原有快捷键、路径及更新设置位于「通用」。

路径留空时，Veyra 会按顺序查找：已安装的 Codex 桌面应用、用户级安装位置（`~/.local/bin/codex`、`~/.codex/packages/standalone/current/bin/codex`）、Homebrew（`/opt/homebrew/bin`、`/usr/local/bin`），最后再检查进程 `PATH`。默认数据目录使用 `CODEX_HOME`（该变量为空或只有空白时按未设置处理）；没有设置该环境变量时使用 `~/.codex`。

路径在按 Return、离开输入框或确认“选择…”后进行本地校验，合法修改自动生效，无需保存。无效输入会保留供修正，实际配置继续使用上次有效值；关闭设置会丢弃无效草稿。“恢复自动检测”会清除两项手动覆盖。Codex 状态表示本地路径是否可用，不代表已完成账号登录或联网验证。

从 Finder 启动的应用通常不会继承终端环境变量。如果自动发现结果不符合实际安装位置，可在终端运行 `which codex` 查看实际路径，再在设置中指定 Codex 可执行文件或数据目录。

## Codex 供应商

在「设置 → 供应商」选择 DeepSeek、Kimi、GLM、MiniMax 或 MiMo。首版面向国内普通按量 API，不包含 Coding Plan。左侧列表只显示一条状态：使用中、已配置或待配置；具体问题（凭据命令不可用、路径变化、鉴权失败、钥匙串锁定）显示在右侧详情标题下方。填写 API Key 后先「仅保存到 Veyra」，应用自动从供应商获取模型列表。选择默认模型后点「设为 Codex 默认」，再完全退出并重启 Codex。不再内置模型列表或推荐默认模型，也不自动选择列表第一项。高级选项提供地址、推理强度和上下文覆盖；供应商返回的上下文窗口和默认推理档位会在启用时采用，并在模型下方显示来源；手动覆盖优先，未提供的能力跟随 Codex 默认值。只有档位列表但没有默认档位时，不自动挑选一档。修改地址需要重新填写 Key。

「仅保存到 Veyra」先将 Key 和设置保存到 Veyra，首次保存或替换 Key 后获取一次模型列表，Codex 当前配置不变。仅修改模型不重复获取；可点击模型区的「刷新模型」或侧栏底部的「重新读取配置」（后者只重读磁盘上的 Codex 配置，不联网）。打开设置、启动应用或菜单切换不自动联网。列表失败不会撤销 Key 保存。首次无缓存时无法启用；暂时网络失败可使用同一数据目录、供应商地址和 Key 引用的缓存。认证失败需刷新成功后才能重新启用。Key 只保存在本机系统钥匙串，界面不会回填已保存的 Key；可以输入新 Key 替换，或单独移除。当前配置或撤销记录仍需要的 Key 无法移除，请先切换到其他供应商，并按需放弃撤销记录。

侧栏底部「＋ 自定义供应商…」保留旧连接、新建、导入和编辑。旧连接名称与 ID 不会被合并或重命名。旧环境变量连接不会自动读取或导入 Key；填写 Key 后可转换为钥匙串认证。复杂认证保持为 Codex 配置引用。

菜单栏「当前供应商」显示配置身份，只列出已配置、可启用的供应商；当前项不可重复切换。管理和撤销统一在设置中操作。侧栏第一项「OpenAI（官方）」可切回官方登录，不要求重新填写 OpenAI Key，切换前会二次确认。左侧高亮表示正在编辑，状态文字表示配置状态，两者独立；没有单独的勾选标记。

切换通过 Codex 配置接口完成，保存版本冲突会停止写入并读回。切换成功提示「已切换，重启 Codex 后生效」。运行中聊天仍使用其实际记录的模型。Veyra 界面退出后，Codex 可调用 Veyra 的无界面取钥命令；移动应用后需重新保存并启用以修复路径。钥匙串锁定时，请先在系统中解锁，再重试。

界面分别显示 Key 已保存、模型列表已获取及错误状态。列表成功不代表模型推理、余额或工具调用已经验证。列表中没有原选中模型时需重新选择；没有硬编码白名单，供应商返回的新模型无需更新应用即可选择。Veyra 不自动发起模型推理请求。请在 Codex 中按需验证真实服务；供应商费用由其普通 API 账户计费。
