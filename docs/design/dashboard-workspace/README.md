## 设计与阅读顺序

- [概览](overview-concept.png)：全局概况 → 最近24小时需要关注 → 按项目分组的主任务列表。
- [统计分析](analytics-concept.png)：期间摘要 → 任务柱状/Token折线 → 年度热力图 → 所选日期任务。
- [任务详情](task-detail-concept.png)：左侧列表 → 右侧摘要与执行记录 → 单轮详情。

实现采用原生SwiftUI与Swift Charts，支持macOS14，不增加第三方依赖。图片不是像素尺寸规范；真实日历必须按日期计算为每周七行、完整周列。失败用红色、未知用橙色，日期和单位均须可读。原生深色、高对比度、键盘、VoiceOver与窗口变化需要单独验证。

## 已确认的数据语义

- 范围为当前配置目录的本机Codex，历史包含可读归档任务；不包含dsh、云端或其他设备。
- 主任务和全部后代组成家族，任务数按家族去重。子任务命中筛选保留父级上下文；资源仅累计一次。
- 全局当前状态不受历史日期、搜索或筛选影响。“进行中”必须有可靠实时证据，读取错误或超过60秒未更新显示不可确认。
- “需要关注”默认最近24小时，收录成员最新的失败、中断或无法确认的执行状态；按家族去重，新的记录覆盖旧失败后重新判断。归档成员不占关注队列。
- Token按已验证增量样本及记录时间汇总，显示已知部分并标注缺失；未知不能填零。缓存输入不是额外Token，不能重复相加。
- 耗时明确为已结束轮次耗时，并行耗时允许相加，不是人的工作时长。未结束与缺失数量另列。正常结束不代表任务目标完成。

## 界面及导航

- 默认概览、明细默认今天。概览与分析的日期和筛选分别保存；分析初始近30天。
- 当前运行和关注数字是列表入口，清除聚焦恢复原查询。
- 宽度1180pt以上支持可调分栏，默认左48%/右52%；窄窗口使用列表/详情切换，返回恢复列表位置。窗口默认1280×900，限制在屏幕可用范围，最小尺寸沿用900×660。
- 两侧独立滚动；任务选中项用稳定ID保留。被筛选排除时明确提示，不跳到其他任务。
- 详情显示资源与轮次摘要、子任务、最新六轮记录、全部轮次及任务信息；精确时间和模型/来源/用量分项在单轮展开内呈现。
- 原任务跳转采用codex://threads/<ID>，打开失败提供复制标识；禁止停止、恢复、重试或修改Codex任务。

## 图表与兼容

- 灰柱为期间内去重主任务数，蓝线为已记录Token，独立单位与尺度；按日/周切换，周任务数不能直接相加日任务数。
- Token缺失断线，部分缺失明确标记。可通过鼠标或可访问日期菜单进入对应明细。
- 热力图默认近一年截止今天，可切换任务数量与Token，日期位置不变。最多五档正值分位强度，重复阈值合并。无活动、缺失和未覆盖分别表达。
- 图表日期只影响明细；年度图选到期间外日期不会改写顶部期间及组合图。
- 原有高级统计、分布、同期比较、数据详情、清除确认和导出继续保留。CSV保持逐轮字段，Markdown标注新口径；导出使用完整期间及筛选，不随图表选日缩窄。
- 保留原有增量索引格式、30秒历史更新、配置路径、安全和隐私约束。
