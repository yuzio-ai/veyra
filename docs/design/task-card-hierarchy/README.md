# 任务卡片信息层级与说明交互

> 图像为设计与实现时的历史快照，可能包含现已退役的 DSH 功能；当前支持范围以[使用指南](../../user-guide.zh-CN.md)为准。

视觉基线为 [A-r02 静态概念稿](concept-A-r02.png)。最终实现叠加用户后续确认的文案、来源名称和上下文位置调整；概念图本身不代表最终原生布局或交互验收。

[紧凑布局方案与静态稿](compact-layout-proposal.md)已按用户确认实施为本地候选，涉及子任务路径、两行进展、展开区留白与分区标题字重。下述结构反映当前源码；运行证据与验收限制由本轮验证记录分别说明。

本轮[验证记录](compact-layout-validation.md)包含未修改的前后截图、双语高度比较、自动检查及人工验收缺口。

## 最终结构

1. 任务标题、状态、来源、模型和“本轮”计时；路径不再独立占行，完整标题与路径保留于标题悬停和辅助功能补充信息。最近进展或操作以行内标签开头，整段最多两行；短内容一行，空内容不占位。显示时折叠原文换行，完整原文保留于悬停和辅助功能。
2. 上下文占用及单条进度条；百分比中等字重，右侧用量为次级颜色，“最近记录”和说明按钮与标题同行。
3. “累计 Token”、一位小数缓存命中率与唯一展开箭头；完整总量保留悬停及辅助功能值。
4. 展开区顶部保留可选角色信息，再依次展示“用量明细”和“会话统计”。上下文不随明细折叠。

用量明细使用条形图标题图标，包含“缓存读取”“未缓存输入”“输出（含推理）”“API 费用（参考）”。缓存百分比不再在展开区重复显示，也不绘制缓存进度条。会话统计使用秒表标题图标，包含“工具调用用时（累计）”“首 Token 延时（平均）”；有效轮次数以“基于 N 轮”与平均值同行，空间不足时在数值组内部换行。

两个分区标题统一为 11pt semibold，以图标、标题和留白分组，不使用虚线框、额外背景或统计分区横线。任务主要块及展开区间距为 8pt，数据子组为 6pt；父子任务之间的横线保留。整行子任务按每层 10pt 缩进，最多三层，展开明细与身份区保持一致。

来源只改展示：非 CLI Codex 来源显示 Codex，命令行显示 Codex CLI，子代理显示分支图标和昵称，无昵称时显示“子代理”。悬停与辅助功能描述保留完整的“子代理：昵称”。内部来源枚举与判定不变，不声称已精确识别为 Codex App。

保留 360pt 面板、原系统材质、字体层级和父子缩进。完整 Token 数遵循系统地区分组，使用等宽数字并右对齐；括号内推理值为输出的子集，以次级颜色呈现。长行重排，不缩小字号或横向裁切。

## 说明与状态

上下文、费用、工具用时、首 Token 延时各有一个原生可聚焦 ⓘ。说明只挂在字段旁，分区标题不再放说明按钮。悬停为简短提示，点击、Space 或 Return 打开锚定浮层；一个菜单只打开一个浮层。Escape 关闭浮层并恢复触发按钮焦点，再次 Escape 关闭主菜单。长说明独立滚动，不改变卡片尺寸；收起相关明细、移除任务或关闭菜单时清理浮层。

说明按钮不是选中开关。鼠标打开的说明关闭后清除临时按下高亮，恢复普通图标外观；键盘打开时保留细线焦点描边。两种方式都保留关闭后的可操作焦点，避免鼠标动作被画成持续选中状态。

费用主行保留金额及“部分估算”“无法估算”等状态；价格依据、核对日期、多模型分项和异常原因放入说明。Codex 费用使用单一金额，摘要两位小数，正数不足一分为 `< US$0.01`，零值为 `≈ US$0.00`；说明中的金额保留原三位精度。只改变显示，不改变计算或价格表。

工具用时说明明确只计已记录的完成调用，并行区间合并。首 Token 延时说明明确按成功完成且有有效计时的轮次求平均。缺失值显示 `—`，零个有效轮次不会被当作零延时。损坏记录等状态仍在卡片可见。

## 验证方式

`TaskInfoInteractionChecks` 使用固定夹具检查顺序、键盘打开、浮层可见、卡片高度不变、替换浮层、焦点恢复、长说明滚动、折叠及任务/窗口移除清理。真实菜单检查另验证第一下 Escape 只关闭说明、第二下关闭菜单，以及六种原生外观中的滚动与焦点恢复。

现有定向与完整测试继续覆盖数据和增量读取，回归覆盖来源、本地化、费用摘要精度、多模型分项和部分估算。使用[固定验证入口](../../development.zh-CN.md)生成中英文布局、运行完整测试并构建无签名通用 Release。固定夹具和布局位图不冒充真实账号或 VoiceOver 人工验收。

数据定义与读取边界见[任务用量与会话统计](../../task-usage-statistics.zh-CN.md)。
