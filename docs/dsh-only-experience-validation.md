# 纯 dsh 用户体验验证

> 历史快照：服务商管理、取钥命令及按服务商屏蔽额度的行为已移除。下文仅记录当时的实现与证据。当前行为见[使用指南](user-guide.zh-CN.md)，移除范围与验收见[清理验证](provider-removal-validation.md)。

日期：2026-10-30（Asia/Shanghai）。

## 实现行为

- Codex 任务读取、Codex 额度/配置能力、dsh 任务读取分别判断。默认来源缺失不作为故障；手动路径失效、已有来源消失和真实读取失败保留来源明确的提示。
- 纯 dsh 隐藏额度与供应商快捷切换，不发起额度请求或配置 RPC，也不维持配置重试。模型设置页说明可选依赖并提供通用设置入口。
- 任务数量来自各来源已确认运行的任务。首次成功读取前显示 `—`，正常空闲显示 `0`；单个来源故障不抹掉另一来源的数量，悬停文案说明可能不完整。
- 通用设置新增 dsh 目录、检测状态、选择目录与恢复自动检测。优先级为手动路径、非空 `DSH_HOME`、`~/.dsh`。无效输入不覆盖有效设置。
- 路径变化仅清除对应来源状态。旧读取和旧配置重载不能覆盖新状态；目录与安装恢复后按现有轮询重新检测。
- 继续只读任务数据。没有新增项目管理、dsh 额度或 dsh 供应商配置。

## 证据边界

以上使用临时记录、模拟进程证据及配置传输夹具，没有使用真实 dsh 安装、账号或供应商 Key。原生菜单检查采用应用内布局位图和合成键盘事件，不能替代实际合成器材质、真人操作和 VoiceOver 验收。较早因并发编辑被标记为不确定的预览不作为通过证据。

## 复查与修复

本轮复查修复五类问题：

1. **dsh 路径提交竞态**：把输入改回当前检测路径时，旧校验仍可能应用；恢复自动检测之前排队的提交也可能重新写入覆盖路径。现在在 UI 事件发生时预留提交版本，校验和应用均核对版本；未改变的检测路径仍保持自动模式。关闭窗口时仍提交有效输入，丢弃无效草稿。
2. **Codex 数据库发现回归**：无关的 `sqlite` 路径不可读或不是目录，会阻断位于数据根目录的有效任务数据库。现在只在未发现数据库时检查该备用目录。
3. **休眠与停止监控竞态**：切换 Codex 路径等待旧 dsh 读取排空后，延迟重启可能撤销休眠或显式停止。现在重启同时核对生命周期版本和休眠状态。
4. **过期的 Codex 能力结果**：可执行文件失效后，晚返回的凭据命令能力或 Key 可用状态可能写回界面。现在在每个相关异步边界核对代际与可用性，停用时清除这些状态，保留凭据刷新开始时原有的清空行为。
5. **dsh 设置被 Codex 阻塞**：Codex 忙碌会禁用整个通用页。现在仅禁用 Codex 设置；原生路径字段遵循禁用状态，dsh 路径仍可编辑。
