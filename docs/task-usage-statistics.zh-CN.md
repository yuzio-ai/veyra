# 任务用量与会话统计

## 显示口径

- **累计 Token**：沿用当前任务来源记录中的累计总量，不合并子任务。缓存命中率为累计缓存输入除以累计输入，不包含输出；输入为零、字段缺失或比例异常时显示 `—`。
- **上下文已用**：读取同一条 `event_msg/token_count` 的 `info.last_token_usage.total_tokens` 和 `info.model_context_window`。直接相除，不扣除固定基线，不从模型名称猜测窗口。数值属于最近记录，不是逐 Token 实时计数。上限为来源报告的窗口，未必等于模型宣传的标称容量。
- **工具调用用时（累计）**：读取 `event_msg/item_completed` 中工具项的 `started_at_ms` / `completed_at_ms`，按轮次与项 ID 去重，再合并会话内的重叠区间。已完成的失败调用也计入；未完成、时间无效及未记录的调用不补估。
- **首 Token 延时（平均）**：成功完成轮次的 `time_to_first_token_ms` 的算术平均，同行显示“基于 N 轮”。只计通过带 `thread_id` 的项目事件或终止事件确认属于当前任务的轮次；继承自 fork 源的轮次、归属未知或冲突的轮次，以及取消、失败及缺失记录均不参与平均。旧记录可能因此显示更少样本或 `—`。它不表示每次模型请求的平均延迟。

## 卡片与说明

参考费用单值摘要使用两位小数，正数不足一分显示 `< US$0.01`；区间费用保持原格式。更多精度、价格依据、模型分项及异常原因移至字段旁的 ⓘ。部分估算、无法估算及计时损坏等状态仍在卡片中可见。

上下文、费用、工具用时和首 Token 延时分别有可键盘访问的原生说明按钮。一个菜单最多打开一个说明浮层，长内容可滚动；Escape 先关闭说明并恢复按钮焦点，再次 Escape 关闭菜单。收起明细、移除任务或关闭菜单会清理对应浮层。说明展示不触发额外历史扫描。同一字段的说明实时更新并保留滚动位置及键盘焦点；内容缩短时只将偏移限制到有效范围，重新打开从顶部开始。费用和会话统计重算期间，仅在任务及来源相同时保留上次说明并标注“更新中”；卡片主行仍只显示当前请求匹配的结果。首次加载不显示旧结果，读取失败会替换旧说明，切换任务或来源不会沿用旧说明。

每个会话独立统计；不读取或合并子代理会话文件。父任务中的协作工具调用只计其自身记录的区间，不额外加上子代理运行时间。消息、推理、计划、子代理活动提示和压缩不作为工具计时。模型纯推理用时、输出 TPS 和上下文分类尚未实现。

## 更新与兼容

上下文随既有尾部监控更新。新的无效快照不能回退到更早的有效快照；压缩或模型切换会清除旧占用，等待新快照。额度更新中 `info: null` 不改变上下文。实际占用超过窗口时保留真实数值，进度条最多填满。

会话统计仅在展开 Token 明细且菜单活动时读取历史。首次扫描后缓存数值，后续只读追加字节。文件替换、截断或同尺寸内容改写时重建缓存；任务、来源或文件修改时间变化会使界面旧结果失效。关闭明细或切换任务会取消原读取。

旧记录缺少计时时显示 `—`，没有有效 TTFT 样本时样本数为零。部分计时记录损坏时显示提示。DSH 不展示尚无可靠来源的上下文和会话统计区。

只保存标识、时间、类型和统计值；不保存消息正文、工具参数、输出或推理内容。解析缓冲区仅用于拼接尚未完成的 JSONL 行。保持只读，不写入 Codex 数据、不新增遥测或推理请求。

## 来源与验证

字段已对照本地近期记录的结构及 [Codex 协议](https://github.com/openai/codex/blob/main/codex-rs/protocol/src/protocol.rs)核对。Codex TUI 的上下文百分比存在固定基线处理，Veyra 的直接占用比例可能与其不同。

回归测试使用临时夹具，覆盖正反向读取、无效最新记录、模型切换、压缩、并行区间、重复项、失败与取消、跨任务隔离、增量读取和文件重建。菜单预览使用固定夹具，不访问真实会话。验证入口见 [开发说明](development.zh-CN.md)。
