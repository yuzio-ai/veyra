# 菜单卡片层级与间距验证

> 归档文档（2026-11-01）：本文是历史验证记录，对应的源码快照、界面和测试数量均已过时。当前行为见[使用指南](../user-guide.zh-CN.md)，当前验证入口见[验证索引](../validation.md)。

## 改动

- 移除主、子任务 Token 汇总行前后的分隔线，与前一组信息及展开明细均保持 12pt 间距。父子任务之间的分隔线保留。
- 额度卡片文字顶部对齐，保持 14pt 内边距和 56pt 进度环；左侧文字换行时进度环仍垂直居中。
- 设置、退出和两个刷新入口共用 28pt 原生图标按钮。默认无底色、无描边；悬停和按下时显示淡圆角背景，禁用时弱化且不响应。
- 原生按钮提供可见键盘焦点，支持空格与回车，保留原有帮助文本、辅助功能名称与标识符。设置和退出操作保持原语义。
- 移除子任务树状竖线，保留逐层缩进、子代理标签、路径、父级辅助功能描述及父子行之间的横向分隔线。
- 项目标题使用 14pt semibold 和主文字颜色；右侧使用 11pt 次要文字区分主任务与子任务。项目间距 20pt，标题与卡片间距 8pt，同项目卡片间距 12pt。
- 主、子任务按运行状态分别计数，共用行展示分类规则，祖先占位不计数；顶部运行总数及项目排序不变。新增文案支持中英文及英文复数。
