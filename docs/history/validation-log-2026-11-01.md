# 2026-11-01 API 参考费用验证快照

本记录只对应本轮源码及产物，不代表后续版本或实际账单。价格表核对日期为 2026-10-31。

## 实现

- 展开任务 Token 详情后显示美元 API 参考费用，标明估算与附加计费限制。Codex 按历史模型分项；dsh 按最后使用的 DeepSeek 模型折算并显示峰谷区间及归属限制。
- 使用 Decimal 计算。缓存读取属于输入，推理属于输出，均不重复计费。未知模型、缺失用量或不一致记录标为未计入，支持部分估算。
- Codex 费用历史独立按需扫描，后续增量读取；保留原有任务监控尾读。父子任务分别计价，缓存仅在内存中保留。
- 修正 DSH 家族测试未隔离 Codex 来源的问题，避免真实本机任务进入测试断言。未改变该项生产行为。
