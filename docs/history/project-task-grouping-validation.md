# 任务按会话项目分组验证

> 归档文档（2026-11-01）：本文是历史验证记录，对应的源码快照、界面和测试数量均已过时。当前行为见[使用指南](../user-guide.zh-CN.md)，当前验证入口见[验证索引](../validation.md)。

## 行为与数据边界

- 明确项目归属优先，目录和公共 Git 目录仅用于缺失归属时的推断。
- 项目定义与会话归属分别遵守迁移状态；部分迁移使用逐会话待迁移名单，完成后不恢复旧映射。
- 空 `project_id` 视为归属数据缺失，允许按目录或公共 Git 目录推断；明确无项目标记阻止推断。迁移后保留该标记，但已有数据库项目 ID 优先。该轮修复与回归证据见[验证日志](validation-log-2026-10-31.md#2026-10-31-缺失归属与明确无项目)。
- 共享 Git 仓库但明确属于不同项目的会话保持独立；独立 clone 不按名称或 remote URL 合并。
- 任务树整体分组，祖先占位行不计数，未归属项目固定在最后。
- Codex、dsh 保留独立状态与错误处理。项目解析失败不修改运行状态或运行数量。
- 项目 I/O 在 actor 中执行，只读数据库、桌面项目字段及 Git 元数据；无新增子进程、网络或持久化。
