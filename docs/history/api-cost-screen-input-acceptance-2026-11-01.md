## 输入与辅助功能

- 电脑工具的合成滚动将原生滚动条从 0 移至 1，底部未知模型原因与基础价格说明完整出现。
- 工具点击“多模型累计”的 Token 行后，辅助功能值变为“已收起”，模型费用节点消失；再次点击后恢复“已展开”、十二个模型及 `≈ US$29.750`。
- 实体键鼠验收：待用户现场反馈。已准备深色降低透明度示例，并要求现场检查收起／展开、底部滚动和 Escape 关闭／返回此前窗口。工具合成输入不计为实体硬件输入通过。
- 原生辅助功能树包含估算标题、总额、十二模型分项、DeepSeek 最后模型限制、部分估算和未知模型原因。展开按钮包含累计 Token 数及展开／收起状态。
- 系统设置中曾确认 VoiceOver 为开启；用户要求跳过声音审查后确认其已关闭，与本轮开始时状态一致。实际朗读、听感和 VoiceOver 导航未验收；辅助功能树不替代这些结论。

VoiceOver 操作口径参考 [Apple 的启停说明](https://support.apple.com/en-gb/guide/voiceover/vo2682/10/mac/27)和[字幕面板说明](https://support.apple.com/en-in/guide/voiceover/unac078/10/mac/27)。本轮未取得字幕面板的朗读证据。
