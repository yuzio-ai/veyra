# 当前验证入口

当前功能为菜单栏额度与本地任务监控、单页设置。设置包含快捷键、Codex 路径及软件更新。Dashboard、服务商与模型管理、连接测试及取钥功能已移除，不能继续作为正向回归场景。

## 回归范围

| 入口 | 当前检查 |
| --- | --- |
| `verify_local.py test` | XCTest、隔离应用诊断、本地验证入口与能耗脚本回归、工程配置检查 |
| `verify_local.py previews settings` | 中英文单页设置、路径编辑、快捷键、更新状态、缩小窗口后的滚动 |
| `verify_local.py previews menu` | 中英文任务、项目分组、用量及 API 参考费用明细、额度、重置次数与来源状态；费用按需读取、模型分项与缺失提示；六种原生菜单外观的长列表滚动、Escape 和焦点恢复 |
| `verify_local.py release-build` | 未签名通用 Release、产物配置与辅助工具编译 |

完整命令与隔离规则见[开发文档](development.zh-CN.md#codex-固定验证入口)。局部测试和 `--native-only` 各自保留独立范围，不能代替完整验证。`SKIP` 表示复用原成功证据。

- “当前版本”跟随本次构建；新版提示采用合成的下一补丁版本。任务标题、进展、路径和额度时钟均为可重复的示例，不读取真实任务或账号。
- 历史设计图、旧 `build/previews*` 目录和旧验证记录只对应当时快照。布局位图与合成事件不能证明系统玻璃合成、硬件输入或 VoiceOver 人工验收。
- 任务明细的视觉定稿与实施记录见[设计记录](design/task-token-breakdown/README.md)。
- API 参考费用的中英文菜单预览、十二组原生窗口外观、焦点与长列表滚动证据见[费用详情验收记录](history/api-cost-native-acceptance-2026-11-01.md)。系统玻璃合成及硬件输入、VoiceOver 人工验收仍与自动检查分别记录。

## 保留的兼容与拒绝测试

旧命令和旧场景仅用于验证启动前拒绝；不同服务商配置用于验证额度不再受模型配置影响。旧日志格式与模型元数据用于只读解析兼容；隐私测试验证凭据、标题和会话正文不会泄漏。这些测试不恢复已移除的功能。

## DSH 退役

DSH 正向场景及专属验证入口已移除。旧场景只保留启动前拒绝测试，原用户数据保持不变。单来源回归继续覆盖仅本地任务、仅额度能力和无 Codex 数据；本次清理证据见[验收记录](history/dsh-removal-validation.md)。
