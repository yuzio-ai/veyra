## 改动

- 主面板、设置状态与辅助功能名称统一为「当前供应商 / Current provider」。「默认模型」及设置中的应用按钮保留原含义。
- 主面板供应商图标为 20pt，与名称间距 8pt；原生菜单图标仍为 16pt，设置侧栏仍为 20pt。保持 360pt 面板宽度、16pt 水平边距、至少 32pt 的整行点击区域及长名称截断。Veyra 品牌标识不变。
- 原生菜单仅列出校验有效的已保存连接，保留原顺序和同名消歧。当前项勾选且禁止重复应用。移除标题、分隔线、撤销、管理和常驻重启说明；宽度按内容决定。
- 空库或全部连接无效时，仅显示禁用提示「暂无可切换的供应商，请在设置中添加」。不自动创建连接。配置不可读、不可写或处理中时禁止切换；不把配置校验当作联网或认证验证。
- 切换成功在入口下方显示「已切换，重启 Codex 后生效」。保留错误和策略覆盖提示。主面板不显示撤销；设置在存在可撤销记录时持续显示撤销入口，即使没有成功提示。
- 沿用原有配置 RPC、未保存编辑保护、版本冲突、字段恢复和存储格式。原生夹具在检查开关前恢复「已打开」前置状态，并记录是否发生恢复；不更改产品开关逻辑。

## 间歇失败与证据边界

早期整块弹窗检查间歇出现 `didNotClose`。状态日志确认失败时弹窗在「关闭」步骤之前已隐藏，测试调用 toggle 后反而重新打开它。现将夹具恢复为已打开状态，再执行原有关闭断言，并在结果中记录 `restoredVisibilityBeforeToggle`。产品窗口逻辑与关闭断言保持不变；没有把失败计为通过。失败记录保留在 `20261026T112225Z-d9beee68`、`20261026T112728Z-7920d234`、`20261026T112904Z-f8d45a9b`、`20261026T113146Z-d77e7403` 验证目录内。

布局位图不能证明系统玻璃合成效果。Esc 检查将合成事件发送到夹具窗口中已聚焦的按钮，不代表硬件键盘或 VoiceOver 人工验收。未执行真实供应商连接请求、Release 签名、公证或发布。
