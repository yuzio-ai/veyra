## English

Veyra 1.1.0 adds bilingual interface, expiry-grouped reset credits, and a cached-input ratio in task details.

### New

- **English and Simplified Chinese interfaces** — Veyra follows your macOS language preferences and supports per-app language settings.
- **Cached input percentage in task details** — see how much of the input token usage was cached.

### Changed

- **Reset credits grouped by expiration** — each batch's remaining credits and validity are now easier to see.

### Requirements

- macOS 14 or later. Supports Apple Silicon and Intel Macs.

### Installation

1. Download `Veyra.zip` from the assets below
2. Unzip, quit the running Veyra app, and replace the old version in Applications
3. Relaunch Veyra

**Full changelog**: https://github.com/yuzio-ai/veyra/compare/v1.0.0...v1.1.0

## 简体中文

Veyra 1.1.0 新增中英文界面、按到期时间分组的重置次数，以及任务详情的缓存输入占比。

### 新增

- **简体中文和英文界面** —— 默认跟随 macOS 语言偏好，也可在系统设置中单独指定应用语言。
- **任务详情缓存输入占比** —— 帮助了解输入 token 中缓存命中的比例。

### 变更

- **重置次数按到期时间分组展示** —— 方便查看各批次的剩余次数与有效期。

### 系统要求

- macOS 14 或更高版本，支持 Apple Silicon 和 Intel Mac。

### 安装

1. 下载下方 Assets 中的 `Veyra.zip`
2. 解压后退出正在运行的 Veyra，将新版本移入「应用程序」目录并替换旧版本
3. 重新启动 Veyra

**完整变更**：https://github.com/yuzio-ai/veyra/compare/v1.0.0...v1.1.0
