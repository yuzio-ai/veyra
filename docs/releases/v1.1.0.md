# Veyra v1.1.0

## 简体中文

- 新增简体中文和英文界面，默认跟随 macOS 语言偏好，也可在系统设置中单独指定应用语言。
- 重置次数按到期时间分组展示，方便查看各批次的剩余次数与有效期。
- 任务详情新增缓存输入占比，帮助了解输入 token 中缓存命中的比例。

需要 macOS 14 或更新版本，支持 Apple Silicon 和 Intel Mac。下载 `Veyra-v1.1.0-macos-universal.zip`，解压后退出正在运行的 Veyra，将新版本移入“应用程序”目录并替换旧版本，然后重新启动。

## English

- Added English and Simplified Chinese interfaces. Veyra follows your macOS language preferences and supports per-app language settings.
- Reset credits are now grouped by expiration, making each batch's remaining credits and validity easier to see.
- Task details now show the cached input percentage to help you understand how much of the input token usage was cached.

Requires macOS 14 or later. Supports Apple Silicon and Intel Macs. Download `Veyra-v1.1.0-macos-universal.zip`, unzip it, quit the running Veyra app, replace the old version in Applications, and relaunch.
