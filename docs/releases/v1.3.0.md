# Veyra v1.3.0

## 简体中文

- 新增本机 dsh 会话监控：正在运行的 dsh 会话与 Codex 任务一起显示在“运行中任务”面板，并展示各会话的 token 用量（输入、输出与缓存输入明细）。默认读取 `~/.dsh`，支持 `DSH_HOME` 环境变量；全程只读，不会修改 dsh 数据。
- Codex 与 dsh 任务同时存在时，任务列表按来源自动分组并标注 Codex / dsh 标题；只有单一来源时保持原有布局不变。
- dsh 读取问题以非侵入方式提示：部分会话记录不可读或无法确认进程时会显示提醒；无法确认状态的会话仍归入“未确认状态”，不计入运行中数量，也不影响 Codex 监控。
- 重要变更：本版本起应用标识（Bundle ID）由 `com.yuzio.veyra` 变更为 `ai.yuzio.veyra`。升级后应用设置（Codex 路径、界面语言、全局快捷键、更新检查偏好等）会重置一次，需要重新配置；应用内更新提示不受影响，从旧版本可正常升级。

需要 macOS 14 或更新版本，支持 Apple Silicon 和 Intel Mac。下载 `Veyra-v1.3.0-macos-universal.zip`，解压后退出正在运行的 Veyra，将新版本移入“应用程序”目录并替换旧版本，然后重新启动。

## English

- Added monitoring of local dsh sessions: running dsh sessions now appear in the Running tasks panel alongside Codex tasks, with per-session token usage (input, output, and cached-input breakdown). Reads `~/.dsh` by default and honors the `DSH_HOME` environment variable; strictly read-only, never modifying dsh data.
- When both Codex and dsh tasks are present, the task list is grouped under Codex / dsh source headings automatically; the layout is unchanged when only one source has tasks.
- dsh read problems surface as unobtrusive notices: a hint appears when some session records are unreadable or dsh processes cannot be verified. Unconfirmed sessions stay in the "Unconfirmed status" section, are excluded from the running count, and never affect Codex monitoring.
- Important: starting with this release, the bundle identifier changes from `com.yuzio.veyra` to `ai.yuzio.veyra`. App settings (Codex paths, interface language, global shortcut, update-check preferences) reset once after upgrading and need to be reconfigured. In-app update notifications are unaffected; upgrading from older versions works as usual.

Requires macOS 14 or later. Supports Apple Silicon and Intel Macs. Download `Veyra-v1.3.0-macos-universal.zip`, unzip it, quit the running Veyra app, replace the old version in Applications, and relaunch.
