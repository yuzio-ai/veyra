## English

Veyra 1.4.0 adds project grouping, detailed token usage, and API reference costs, with automatic quota sync and improved DeepSeek Harness monitoring.

### New

- **Project grouping** — tasks are grouped by their recorded project, with directory and Git worktree matching when membership is missing. Parent and subagent tasks stay together within each project.
- **Token details and API reference costs** — expand a task's token row to inspect cached input, uncached input, output, and included reasoning tokens. Estimated costs are shown in USD, with model breakdowns for Codex and peak/off-peak ranges for supported DeepSeek models.
- **DeepSeek Harness workspaces and subagents** — dsh tasks use their own workspace membership and nest subagent sessions under their parents. Source badges and model tooltips provide clearer product, provider, and reasoning-effort context.

### Changed

- **Automatic online quota sync** — quotas now come from the signed-in Codex account API rather than local session snapshots. Sync runs every minute while tasks run and every hour while idle, with manual refresh and failure backoff.
- **Clearer menu layout** — a quota ring and a separate running-task count appear in the menu bar. The panel places the local-scope indicator beside running tasks and removes the manual task-refresh button; local task checks continue automatically.
- **Independent dsh monitoring** — monitoring dsh alone requires no Codex installation. Its data directory can be selected in settings; unavailable sources show their own warnings while the other source continues working.
- **Single-page settings** — shortcuts, Codex and dsh paths, and software updates share one scrollable settings page.

### Fixed

- **Missing project membership** — an empty project field no longer prevents directory-based grouping. Explicit local no-project choices remain respected across migration, and recorded project IDs take precedence.
- **Menu keyboard focus** — opening from another app supports Escape to close the panel and restore focus to the previous app.
- **Counts during source failures** — confirmed tasks from an available source remain counted, with a warning when the total may be incomplete.

### Known limitations

- **Reference costs are estimates** — prices are bundled with Veyra and exclude additional charges. Estimates are not actual bills or subscription deductions. Missing or unpriced usage is marked as partial or unavailable; dsh uses the last recorded model, so historical model changes may affect its estimate.
- **Local tasks only** — cloud tasks and tasks on other devices are not included. Codex subscription quota sync requires a local Codex installation and ChatGPT sign-in; API-key authentication does not provide subscription quotas.

### Requirements

- macOS 14 or later. Supports Apple Silicon and Intel Macs.

### Installation

1. Download `Veyra.zip` from the assets below
2. Unzip, quit the running Veyra app, and replace the old version in Applications
3. Relaunch Veyra

**Full changelog**: https://github.com/yuzio-ai/veyra/compare/v1.3.2...v1.4.0

## 简体中文

Veyra 1.4.0 新增项目分组、Token 用量明细与 API 参考费用，支持自动同步额度，并改进 DeepSeek Harness 任务监控。

### 新增

- **项目分组** —— 按会话记录的项目归属展示任务；归属缺失时，通过目录与 Git worktree 匹配。项目内保留完整的父子任务树。
- **Token 明细与 API 参考费用** —— 展开任务用量行，可查看缓存读取、未缓存输入、输出及其中包含的推理用量。参考费用统一显示美元，Codex 支持按模型分项，受支持的 DeepSeek 模型显示峰谷价格区间。
- **DeepSeek Harness 工作区与子代理** —— dsh 优先使用自身的工作区归属，子代理会话嵌套在父任务下。来源徽章和模型提示补充产品、服务商与推理强度信息。

### 变更

- **自动联网同步额度** —— 额度改为读取当前登录的 Codex 账号接口，不再使用本地会话快照。任务运行时每分钟同步，空闲时每小时同步，保留手动刷新和失败退避。
- **菜单布局更清晰** —— 菜单栏以圆环展示额度，并独立显示运行任务数。面板将本机范围提示放在任务标题行，移除手动任务刷新按钮；本地任务继续自动检查。
- **独立监控 dsh** —— 仅监控 dsh 无需安装 Codex，可在设置中选择数据目录。来源故障分别提示，不影响另一来源继续监控。
- **单页设置** —— 快捷键、Codex 与 dsh 路径、软件更新集中在可滚动的设置页。

### 修复

- **缺失项目归属** —— 空项目字段不再阻止按目录分组。迁移后仍尊重本机明确的无项目选择，已有项目 ID 优先。
- **菜单键盘焦点** —— 从其他应用打开面板后，可按 Escape 关闭并将焦点返回原应用。
- **来源故障时的计数** —— 一个来源不可用时，继续统计另一来源已确认运行的任务，并提示总数可能不完整。

### 已知限制

- **参考费用为估算值** —— 价格表随 Veyra 版本提供，不含附加计费，不代表实际账单或订阅额度扣减。缺失或未定价的用量显示为部分估算或暂不可用；dsh 使用最后记录的模型，历史换模型可能造成偏差。
- **仅显示本机任务** —— 不包含云端或其他设备任务。Codex 订阅额度同步需要本机 Codex 和 ChatGPT 登录；API Key 认证不提供订阅额度。

### 系统要求

- macOS 14 或更高版本，支持 Apple Silicon 和 Intel Mac。

### 安装

1. 下载下方 Assets 中的 `Veyra.zip`
2. 解压后退出正在运行的 Veyra，将新版本移入「应用程序」目录并替换旧版本
3. 重新启动 Veyra
