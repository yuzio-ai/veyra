## English

Veyra 1.5.0 adds recorded context usage, session timing statistics, and field explanations in a clearer task card.

### New

- **Recorded context usage** — Codex tasks show the latest recorded context usage and reported window size, including while token details are collapsed.
- **Session timing statistics** — expanded Codex tasks show cumulative tool time, average first-token latency, and the number of contributing turns. Overlapping tool intervals count once; latency samples must belong to the current task and come from successfully completed turns with valid timing.
- **Field explanations** — open context, cost, and timing explanations with a click, Space, or Return. Live updates preserve scrolling and keyboard focus. During recalculation, explanations retain the previous result for the same task and source and show an updating status. Escape closes the explanation first, then the menu.

### Changed

- **Clearer task cards** — cache hit rate appears beside cumulative tokens, with usage details and session statistics grouped below. Turn duration and output that includes reasoning have clearer labels.
- **Compact reference costs** — single-value summaries use two decimal places; positive values below one cent show `< US$0.01`. Detailed precision, model breakdowns, and pricing notes remain available in the explanation. Cost ranges keep their existing format.
- **Source names** — task badges use Codex, Codex CLI, and DSH, with subagent nicknames preserved.

### Known limitations

- **Recorded data only** — context usage updates with recorded token statistics. Missing timing records are not estimated, and turns with unknown or conflicting ownership do not contribute to average latency. DSH does not yet show context usage or session timing statistics.
- **Reference costs are estimates** — they are not actual bills or subscription deductions and exclude additional charges. dsh estimates use the last recorded model, so historical model changes may affect the result.

### Requirements

- macOS 14 or later. Supports Apple Silicon and Intel Macs.

### Installation

1. Download `Veyra.zip` from the assets below
2. Unzip, quit the running Veyra app, and replace the old version in Applications
3. Relaunch Veyra

**Full changelog**: https://github.com/yuzio-ai/veyra/compare/v1.4.0...v1.5.0

## 简体中文

Veyra 1.5.0 新增上下文占用、会话计时统计和字段说明，并重新整理任务卡片的信息层级。

### 新增

- **上下文占用** —— Codex 任务显示最近记录的上下文用量和来源报告的窗口大小，收起 Token 明细时仍可查看。
- **会话计时统计** —— 展开 Codex 任务后，可查看工具调用累计用时、首 Token 平均延时及有效样本轮数。重叠工具区间只计一次；延时仅统计已确认属于当前任务、成功完成且计时有效的轮次。
- **字段说明** —— 点击、Space 或 Return 可打开上下文、费用及计时说明。说明实时更新并保留滚动位置和键盘焦点；重算期间，同一任务和来源的说明保留上次结果并标记“更新中”。Escape 先关闭说明，再次按下关闭菜单。

### 变更

- **任务卡片层级** —— 缓存命中率移至累计 Token 摘要，展开后分组显示用量明细和会话统计；明确标注本轮用时及输出包含的推理用量。
- **费用摘要更紧凑** —— 单值摘要保留两位小数，正数不足一分显示 `< US$0.01`。更多精度、模型分项和价格依据放入说明；区间费用保留原格式。
- **来源名称更清晰** —— 任务徽章使用 Codex、Codex CLI 和 DSH，保留子代理昵称。

### 已知限制

- **以来源记录为准** —— 上下文随记录的 Token 统计更新；缺失计时不补估，归属未知或冲突的轮次不参与平均延时。DSH 暂不显示上下文占用和会话计时统计。
- **参考费用为估算值** —— 不代表实际账单或订阅额度扣减，不含附加计费；dsh 使用最后记录的模型，历史换模型可能造成偏差。

### 系统要求

- macOS 14 或更高版本，支持 Apple Silicon 和 Intel Mac。

### 安装

1. 下载下方 Assets 中的 `Veyra.zip`
2. 解压后退出正在运行的 Veyra，将新版本移入「应用程序」目录并替换旧版本
3. 重新启动 Veyra
