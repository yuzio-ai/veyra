## English

Veyra 1.7.0 identifies recorded session origins across Codex clients and narrows directory-based project inference to primary roots.

### Changed

- **Recorded task origins** — task badges display the recorded session originator (`Codex Desktop`, `Codex CLI`, `Codex IDE`, `ChatGPT Work`, `T3 Code`, or `Codex` when unavailable) read from the Codex database or rollout session metadata, with tooltips noting when a session continues across clients. Task identity badges and parent task labels now use plain text without icons.

### Fixed

- **Primary-root project inference** — when explicit project membership is missing, path and Git worktree inference now matches only each project's primary root (`position = 0` in the database, a single root when `position` is absent, or the first directory in legacy desktop state), preventing another project's secondary directories from claiming or conflicting with a project's primary directory.

### Engineering

- **Executable discovery test isolation** — `CodexLocation.resolve` accepts an injectable executable check so unit tests stay isolated from tools installed on the host machine.

### Known limitations

- **Recorded origins reflect session creation** — when a session starts in one client and continues in another, the displayed origin badge still reflects the recorded originator rather than the active client.

### Requirements

- macOS 14 or later. Supports Apple Silicon and Intel Macs.

### Installation

1. Download `Veyra.zip` from the assets below
2. Unzip, quit the running Veyra app, and replace the old version in Applications
3. Relaunch Veyra

## 简体中文

Veyra 1.7.0 识别任务记录中的会话来源客户端，并收敛无明确归属时的项目目录推断范围。

### 变更

- **识别记录来源** —— 任务徽章改为根据 Codex 数据库或会话日志头记录的来源字段展示 `Codex Desktop`、`Codex CLI`、`Codex IDE`、`ChatGPT Work`、`T3 Code`（无法识别时显示 `Codex`），并在悬停提示中说明跨客户端续接时记录来源可能与当前客户端不同。任务身份徽章与“父任务”标签移除冗余图标，仅保留文本。

### 修复

- **按主目录推断项目归属** —— 缺少明确归属数据时，路径与 Git worktree 推断仅匹配项目主目录（数据库以 `position = 0` 为主目录，缺少位置字段时仅单目录项目参与推断，旧桌面数据取首个目录），避免其他项目的次级目录抢占或引发归属冲突。

### 工程质量

- **隔离可执行文件探测测试** —— `CodexLocation.resolve` 支持注入可执行文件检查逻辑，避免单元测试受宿主机已安装工具环境干扰。

### 已知限制

- **会话来源以记录为准** —— 若同一会话在一个客户端创建并在另一个客户端中继续执行，任务徽章仍显示记录中的原始来源，不一定反映当前客户端。

### 系统要求

- macOS 14 或更高版本，支持 Apple Silicon 和 Intel Mac。

### 安装

1. 下载下方 Assets 中的 `Veyra.zip`
2. 解压后退出正在运行的 Veyra，将新版本移入「应用程序」目录并替换旧版本
3. 重新启动 Veyra
