## English

Veyra 1.3.2 fixes dsh task detection for DeepSeek Harness Desktop.

### Fixed

- **DeepSeek Harness Desktop sessions now confirm as running** — Veyra previously only recognized session locks held by the `node` CLI, so Desktop sessions stayed stuck under "Unconfirmed status" even while active. Locks held by `DeepSeek Harness` are now detected too.

### Requirements

- macOS 14 or later. Supports Apple Silicon and Intel Macs.

### Installation

1. Download `Veyra.zip` from the assets below
2. Unzip, quit the running Veyra app, and replace the old version in Applications
3. Relaunch Veyra

**Full changelog**: https://github.com/yuzio-ai/veyra/compare/v1.3.0...v1.3.2

## 简体中文

Veyra 1.3.2 修复 DeepSeek Harness Desktop 下 dsh 任务的运行状态识别。

### 修复

- **DeepSeek Harness Desktop 会话可确认为运行中** —— 此前只识别 `node` 命令行持有的会话锁，桌面端会话即使在运行也一直停留在“状态待确认”。现在同样识别 `DeepSeek Harness` 持有的锁。

### 系统要求

- macOS 14 或更高版本，支持 Apple Silicon 和 Intel Mac。

### 安装

1. 下载下方 Assets 中的 `Veyra.zip`
2. 解压后退出正在运行的 Veyra，将新版本移入「应用程序」目录并替换旧版本
3. 重新启动 Veyra

**完整变更**：https://github.com/yuzio-ai/veyra/compare/v1.3.0...v1.3.2
