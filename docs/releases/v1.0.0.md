## English

Veyra 1.0.0 is the initial release of a macOS menu bar app for monitoring Codex quotas and local tasks.

### Requirements

- macOS 14 or later. Supports Apple Silicon and Intel Macs.

### Installation

1. Download `Veyra.zip` from the assets below
2. Unzip and move `Veyra.app` to Applications
3. Launch Veyra — access it from the menu bar

Signed with Developer ID and notarized by Apple.

**Full changelog**: https://github.com/yuzio-ai/veyra/commits/v1.0.0

## 简体中文

Veyra 1.0.0 是首个正式版本 —— 一款用于监控 Codex 额度和本机任务的 macOS 菜单栏应用。

### 系统要求

- macOS 14 或更高版本，支持 Apple Silicon 和 Intel Mac。

1. 下载下方 Assets 中的 `Veyra.zip`
