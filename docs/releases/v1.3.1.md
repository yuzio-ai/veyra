## English

Veyra 1.3.1 fixes Codex executable discovery for user-level installs and the handling of a blank `CODEX_HOME`.

### Changed

- **Clearer missing-executable guidance** — the settings status row and the quota failure notice now share one message that suggests running `which codex` in Terminal to find the path, then specifying it in Settings.

### Fixed

- **Codex executable discovery** — user-level installs (`~/.local/bin/codex` and `~/.codex/packages/standalone/current/bin/codex`) are now found automatically. Previously Veyra only checked desktop app bundles, Homebrew, and the inherited `PATH`, which a Finder-launched app rarely sees.
- **Blank `CODEX_HOME` treated as unset** — an empty or whitespace-only `CODEX_HOME` used to resolve to the filesystem root for Finder-launched Veyra; it now falls back to `~/.codex` like an unset variable.

### Engineering

- **Release note convention** — pinned style template with config plus render/check scripts, and the past release notes normalized to it.

### Requirements

- macOS 14 or later. Supports Apple Silicon and Intel Macs.

### Installation

1. Download `Veyra.zip` from the assets below
2. Unzip, quit the running Veyra app, and replace the old version in Applications
3. Relaunch Veyra

**Full changelog**: https://github.com/yuzio-ai/veyra/compare/v1.3.0...v1.3.1

## 简体中文

Veyra 1.3.1 修复用户级安装位置下 Codex 可执行文件的自动发现，并修正空白 `CODEX_HOME` 的处理。

### 变更

- **缺失可执行文件的提示更明确** —— 设置状态行与额度失败提示现在共用同一条说明，建议在终端运行 `which codex` 查找路径，再在设置中指定。

### 修复

- **Codex 可执行文件自动发现** —— 现在会自动找到用户级安装位置（`~/.local/bin/codex` 与 `~/.codex/packages/standalone/current/bin/codex`）。此前只检查桌面应用、Homebrew 与继承的 `PATH`，而 Finder 启动的应用往往看不到 shell 的 `PATH`。
- **空白 `CODEX_HOME` 按未设置处理** —— 此前空或仅含空白的 `CODEX_HOME` 在 Finder 启动下会解析到文件系统根目录；现在与未设置时一致，回退到 `~/.codex`。

### 工程质量

- **发布说明规范** —— 固定样式模板、配置与生成/检查脚本，并将历史发布说明规范化。

### 系统要求

- macOS 14 或更高版本，支持 Apple Silicon 和 Intel Mac。

### 安装

1. 下载下方 Assets 中的 `Veyra.zip`
2. 解压后退出正在运行的 Veyra，将新版本移入「应用程序」目录并替换旧版本
3. 重新启动 Veyra

**完整变更**：https://github.com/yuzio-ai/veyra/compare/v1.3.0...v1.3.1
