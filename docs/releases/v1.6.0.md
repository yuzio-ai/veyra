## English

Veyra 1.6.0 adds dual quota rings, more compact task cards, and an adaptable settings window, and retires DSH monitoring.

### New

- **Dual quota rings** — the menu bar shows up to two Codex quota windows, ordered from shorter to longer. Each ring and its percentage use their own remaining-quota color: red below 10%, orange from 10% to below 30%, and the normal color otherwise. Cached values retain their colors and are marked with an asterisk.

### Changed

- **Compact task cards** — task paths move into title tooltips and accessibility hints. Progress labels and text share up to two lines, with the full text available on hover and through accessibility. Tighter spacing and clearer statistics headings reduce scrolling while preserving parent and subagent grouping.
- **Adaptable settings** — the settings window supports resizing and scrolling, remembers its size and position, and keeps its content within the available screen when displays change. Controls adapt to the available width while preserving editing state.
- **Codex-only monitoring** — DSH monitoring and its settings have been removed. Veyra no longer reads DSH tasks or estimates their costs. Existing DSH data and saved preferences are left untouched.

### Fixed

- **Quota refresh cooldown** — the refresh control becomes available when the real cooldown expires, including after closing and reopening the panel. Repeated clicks and keyboard activation respect the same cooldown.
- **Task-data notices** — task-data failures share one summary with details, and cached tasks remain unconfirmed until their source recovers. Quota availability is handled separately from task-data status.
- **Settings geometry** — restored windows stay within the visible screen, minimum sizing is enforced, and shorter windows allow scrolling to all settings.

### Known limitations

- **Recorded data only** — context usage and session timing depend on available Codex records. Missing values are not estimated. API reference costs remain estimates, not actual bills or subscription deductions.

### Requirements

- macOS 14 or later. Supports Apple Silicon and Intel Macs.

### Installation

1. Download `Veyra.zip` from the assets below
2. Unzip, quit the running Veyra app, and replace the old version in Applications
3. Relaunch Veyra

## 简体中文

Veyra 1.6.0 新增额度双环，压缩任务卡片布局，改进设置窗口，并移除 DSH 监控支持。

### 新增

- **额度双环** —— 菜单栏最多显示两个 Codex 额度窗口，按周期从短到长排列。每个圆环和百分比独立配色：余量不足 10% 为红色，10% 至不足 30% 为橙色，其余使用正常颜色。缓存额度保留配色，并以星号标记。

### 变更

- **紧凑任务卡片** —— 任务路径移至标题悬停提示和辅助功能提示。进展标签与正文合并为最多两行，完整内容仍可通过悬停和辅助功能读取。收紧间距并强化统计标题，减少滚动，保留父子任务分组。
- **自适应设置窗口** —— 支持缩放和滚动，记住窗口尺寸与位置，并在显示器变化时将窗口保持在可见范围。控件随可用宽度调整排列，保留编辑状态。
- **仅保留 Codex 监控** —— 已移除 DSH 监控及相关设置，不再读取 DSH 任务或估算其费用。现有 DSH 数据及已保存的偏好设置保持不变。

### 修复

- **额度刷新冷却** —— 冷却到期后，刷新控件按真实时间恢复可用；关闭并重新打开面板后仍正确生效。连续点击和键盘操作遵守相同的冷却限制。
- **任务数据提醒** —— 任务数据异常合并为一条摘要，可查看详情；缓存任务在来源恢复前保留为未确认状态。额度可用性与任务数据状态分别处理。
- **设置窗口边界** —— 恢复窗口时保持在屏幕可见范围，落实最小尺寸限制，缩小高度后可滚动访问全部设置。

### 已知限制

- **以来源记录为准** —— 上下文占用与会话计时依赖可用的 Codex 记录，缺失值不补估。API 参考费用仍为估算值，不代表实际账单或订阅额度扣减。

### 系统要求

- macOS 14 或更高版本，支持 Apple Silicon 和 Intel Mac。

### 安装

1. 下载下方 Assets 中的 `Veyra.zip`
2. 解压后退出正在运行的 Veyra，将新版本移入「应用程序」目录并替换旧版本
3. 重新启动 Veyra
