## English

Veyra 1.2.0 adds a customizable global shortcut and in-app update checks, redesigns settings, and shows public plan names.

### New

- **Customizable global shortcut** — show or hide the monitor panel at any time.
- **In-app update checks** — get notified about new GitHub releases, check manually, or turn this off in settings.

### Changed

- **Redesigned settings window** — Codex path changes now save automatically with no manual confirmation.
- **Public plan names** — account plans now show names such as Free, Plus, and Pro instead of internal tier identifiers.
- **Stale uncertain tasks hidden** — uncertain tasks with no activity for 24 hours and no matching running process are no longer shown.

### Fixed

- **Online quota buckets kept on refresh** — local refreshes could drop online quota buckets.

### Requirements

- macOS 14 or later. Supports Apple Silicon and Intel Macs.

### Installation

1. Download `Veyra.zip` from the assets below
2. Unzip, quit the running Veyra app, and replace the old version in Applications
3. Relaunch Veyra

**Full changelog**: https://github.com/yuzio-ai/veyra/compare/v1.1.0...v1.2.0

## 简体中文

Veyra 1.2.0 新增可自定义全局快捷键与应用内更新检查，重新设计设置界面并改用公开套餐名称。

### 新增

- **可自定义全局快捷键** —— 随时唤起或隐藏监控面板。
- **应用内更新检查** —— 自动提示 GitHub 上的新版本，也可在设置中手动检查或关闭。

### 变更

- **设置界面重新设计** —— Codex 路径修改后自动保存，无需手动确认。
- **套餐显示公开名称** —— 账号套餐显示为 Free、Plus、Pro 等公开名称，替代内部等级标识。
- **陈旧的不确定任务不再显示** —— 超过 24 小时无活动且未匹配到运行进程的不确定任务不再展示。

### 修复

- **本地刷新不再丢失在线配额分组** —— 修复本地刷新可能丢失在线配额分组的问题。

### 系统要求

- macOS 14 或更高版本，支持 Apple Silicon 和 Intel Mac。

### 安装

1. 下载下方 Assets 中的 `Veyra.zip`
2. 解压后退出正在运行的 Veyra，将新版本移入「应用程序」目录并替换旧版本
3. 重新启动 Veyra

**完整变更**：https://github.com/yuzio-ai/veyra/compare/v1.1.0...v1.2.0
