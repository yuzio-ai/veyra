# Veyra v1.2.0

## 简体中文

- 新增可自定义的全局快捷键，随时唤起或隐藏监控面板。
- 设置界面重新设计，Codex 路径修改后自动保存，无需手动确认。
- 新增应用内更新检查，自动提示 GitHub 上的新版本，也可在设置中手动检查或关闭。
- 账号套餐显示为公开名称（如 Free、Plus、Pro），替代内部等级标识。
- 修复本地刷新可能丢失在线配额分组的问题。
- 超过 24 小时无活动且未匹配到运行进程的不确定任务不再显示。

需要 macOS 14 或更新版本，支持 Apple Silicon 和 Intel Mac。下载 `Veyra-v1.2.0-macos-universal.zip`，解压后退出正在运行的 Veyra，将新版本移入“应用程序”目录并替换旧版本，然后重新启动。

## English

- Added a customizable global shortcut to show or hide the monitor panel at any time.
- Redesigned the settings window. Codex path changes now save automatically with no manual confirmation.
- Added in-app update checks that notify you about new GitHub releases. You can also check manually or turn this off in settings.
- Account plans now show public names such as Free, Plus, and Pro instead of internal tier identifiers.
- Fixed local refreshes that could drop online quota buckets.
- Uncertain tasks with no activity for 24 hours and no matching running process are no longer shown.

Requires macOS 14 or later. Supports Apple Silicon and Intel Macs. Download `Veyra-v1.2.0-macos-universal.zip`, unzip it, quit the running Veyra app, replace the old version in Applications, and relaunch.
