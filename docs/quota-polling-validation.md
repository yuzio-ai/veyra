# 额度轮询与状态栏验证

> 历史快照：服务商管理、取钥命令及按服务商屏蔽额度的行为已移除。下文仅记录当时的实现与证据。当前行为见[使用指南](user-guide.zh-CN.md)，移除范围与验收见[清理验证](provider-removal-validation.md)。

日期：2026-10-30。

## 行为

- 官方供应商启动后获取在线额度；有已确认运行任务时每 60 秒获取一次，空闲时每 3600 秒获取一次。
- 任务状态变化会调整下次额度刷新时间。额度请求独立于本地任务读取，不阻塞任务列表。
- 手动和自动刷新共享请求合并、额度请求的 60 秒最短间隔和失败退避；保留服务端 Retry-After。
- 第三方供应商隐藏额度卡片、重置次数、状态栏圆环和底栏额度文字，并停止轮询。切回官方供应商后重新获取。
- 配置变更立即通知监控状态；外部配置变更在本地轮询时检测。旧供应商或旧目录的延迟响应不能覆盖当前状态。
- 本地日志继续用于任务状态和 token，不再为额度补读归档日志，也不将本地额度记录合并到在线结果。
- 状态栏圆环与中心数字由同一个快照值绘制，数字不显示百分号并增大字号。任务数量显示在独立圆角矩形中，不使用运行三角，空闲为 0，来源无法可靠确认时为 —。

验证使用隔离数据和模拟接口，没有查询真实账号额度，没有替换已安装应用，也未执行签名 Release 构建。原生弹窗检查和布局位图不等同于真实账号运行、系统菜单栏合成效果或完整 VoiceOver 验收。
