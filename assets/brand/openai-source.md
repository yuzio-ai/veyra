# OpenAI provider mark

The OpenAI Blossom mark belongs to OpenAI. It identifies the official OpenAI service in Veyra; it is not Veyra branding or an endorsement.

- Guidelines: https://openai.com/brand/
- Original archive: https://cdn.openai.com/brand/OpenAI-Logos-2025.zip
- Downloaded: 2026-10-26.
- Source SVG: `OpenAI-logos(new)/SVGs/OpenAI-black-monoblossom.svg`, copied unchanged to `openai-monoblossom.svg`.
- Bundled PNG: `OpenAI-logos(new)/PNGs/OpenAI-black-monoblossom.png`, copied unchanged to `Veyra/Resources/OpenAIProvider.png`.

AppKit treats the monochrome image as a template to follow the system light/dark appearance. Custom connections use a neutral initial instead of a brand mark. No runtime image downloads occur.
