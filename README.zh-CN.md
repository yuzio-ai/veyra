Veyra 是使用 Swift 6 和 SwiftUI 编写的原生 macOS 菜单栏应用，用于监控 Codex 额度及本机 Codex、dsh 任务。它集中展示额度窗口与重置时间，以及运行任务的状态、模型、耗时和 token 用量，不打断当前工作。

## 使用要求

- macOS 14 或更新版本。
- 本机使用 Codex 或 dsh；仅监控 dsh 无需安装 Codex。
- Codex 额度同步和供应商配置需要本机的 `codex` 可执行文件与数据目录。额度同步还需要 Codex 的 ChatGPT 登录，无需填写 API Key。

## 安装

从 [GitHub Releases](https://github.com/yuzio-ai/veyra/releases) 下载最新压缩包，解压后将 `Veyra.app` 移入“应用程序”目录。从“应用程序”启动 Veyra；它只出现在菜单栏中，不显示 Dock 图标。

## 使用

Veyra 运行时，在任意应用中按 **Control + Option + V**（`⌃⌥V`）即可显示或隐藏面板；按 **Esc** 或点击外部关闭。在 **设置 → 快捷键** 中可以录入其他组合、关闭功能或恢复默认。组合须包含 Control、Option 或 Command，Shift 可选。录入时暂停当前快捷键，按 Esc 或离开录入控件取消；冲突会在设置中提示，并保留原有选择。无需辅助功能或输入监控权限。

点击菜单栏中的 Veyra 图标，可查看运行中的任务家族、任务状态、耗时、累计 token 和在线额度。额度在有运行任务时每分钟同步一次，空闲时每小时同步一次，也可点击额度刷新按钮手动同步。切换到第三方供应商后隐藏额度并暂停同步。菜单栏以圆环和不带百分号的放大数字显示剩余额度，以圆角矩形中的数字显示运行任务数。如果自动发现的 Codex 安装不正确，可在 Veyra 设置中指定可执行文件或数据目录。合法路径在按 Return、离开输入框或确认文件选择后自动生效；清空单个字段会恢复该字段的自动检测，“恢复自动检测”会清除两项手动设置。

仅使用 dsh 时，面板显示本地任务和已确认运行数量，隐藏 Codex 额度与供应商切换，也不发起相关请求。在 **设置 → 通用 → dsh** 可选择数据目录；优先使用手动路径，其次为非空的 `DSH_HOME`，最后为 `~/.dsh`。从 Finder 启动通常不会继承终端环境变量。单个来源读取失败时，另一来源的任务仍正常显示，提示会说明数量可能不完整。

Veyra 在启动和打开菜单时检查公开的 GitHub Releases，每 24 小时最多自动检查一次。可在“设置 → 软件更新”关闭自动检查，或点击“检查更新…”手动查询。发现新版后，“前往下载”会在浏览器打开对应版本页面。下载安装包后，退出 Veyra，再替换“应用程序”中的 App；Veyra 不会自行下载或安装更新。更新检查不使用 GitHub Token 或 Codex 凭据。

Veyra 以只读方式监控已有本地数据，不创建、恢复或控制任务，不自动触发模型推理请求，不复制 Codex 登录凭据，也不修改 Codex 数据库和会话文件。供应商设置中的「测试连接」由用户主动触发，会发送少量模型请求，可能产生 API 费用。

在 **设置 → 模型** 选择 DeepSeek、Kimi、GLM、MiniMax 或 MiMo，填写普通按量 API 的 Key 并「保存」，再点击「刷新模型」获取列表。应用不内置模型清单，也不自动选择第一项。选择模型后，点击「保存并设为默认」或「设为默认」，然后重启 Codex。当前默认服务商使用「保存并应用」或「应用」更新配置。保存只更新 Veyra，不会自动获取模型或切换 Codex；打开设置、启动应用和菜单切换也不自动获取。侧栏高亮表示正在编辑，勾选表示新会话默认供应商；配置状态和问题显示在详情页。内置供应商的国内地址与认证已预置，上下文窗口和默认推理档位采用供应商元数据，手动覆盖优先，缺失能力跟随 Codex 默认值。Key 只存入本机系统钥匙串，Codex 通过 Veyra 的无界面取钥命令读取，配置不含 Key。侧栏「添加服务商」创建自定义连接。外部 Codex 配置变化会自动同步，额度调度随当前供应商调整。旧连接保留原有身份；旧环境变量连接需要用户填写 Key 后转换，不读取原环境变量值。菜单栏可切换已配置供应商，也可返回官方 OpenAI 登录。自定义连接支持用户主动测试 Responses 兼容性；测试可能产生费用，不代表完整工具能力已验证。

当一次成功的进程检查找不到匹配的 Codex 进程，且任务已连续 24 小时没有新的活动记录时，状态待确认的任务会被隐藏。仍有匹配进程的任务无论多久都保留；进程检查失败时保持原有的待确认状态和警告。这一显示过滤不会修改任务历史。

Veyra 支持简体中文和英文，默认跟随 macOS 语言偏好。可在 **系统设置 → 通用 → 语言与地区 → 应用程序** 中为 Veyra 单独指定语言，重新启动后生效。没有匹配语言时使用英文，日期和时间遵循系统区域设置。任务标题与 Codex 原始进展保留原文。
